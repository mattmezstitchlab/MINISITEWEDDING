# Les 365 fiches de l’année

> Document **engendré** comme l’autre : `npm run prompts` le réécrit à partir de `src/lib/fichesAnnee.ts`.
> Tout ce qui est ici est vérifié par les tests du site — ce qui n’y est pas n’est pas « à peu près », c’est à documenter.

## Le tableau de l’année

- **365 journées**, une fiche chacune.
- **16 fiches documentées** — origine, époque, lieu, métier, savoir-faire, culture, sens, ponts, casting.
- **330 fiches amorcées** — le sens du prénom, et souvent le métier par la tradition : la journée a déjà **une porte**.
- **19 fiches sans rien** — et ce sont **des fêtes**, pas des personnes : 20 journées de l’année sont des fêtes (la Toussaint, l’Assomption, les armistices), dont la fiche est un texte, pas une biographie.

Autrement dit : **toutes les journées qui portent un prénom ont au moins le sens de ce prénom.** Rien n’est inventé pour combler les autres — elles disent leur nature.

Ce que la tradition et les dictionnaires couvrent déjà : **346 journées** ont le sens de leur prénom, **29 journées** ont leur métier, et cela ouvre **41 portes** du mariage différentes.
